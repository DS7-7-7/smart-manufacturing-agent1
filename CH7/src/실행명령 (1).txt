========================================
CH7 실습 실행 명령
========================================

[사전 준비]
1) 최상위 폴더의 llm_client.py 와 .env 가 설정되어 있어야 한다.
2) Ollama 임베딩 모델을 미리 받는다.
   ollama pull bge-m3
3) data/manuals/ 폴더에 PDF 파일을 넣는다.
   예) safety_guide.pdf, equipment_manual.pdf


[7.7 실습] PDF 매뉴얼을 벡터 DB에 적재
------------------------------------------
# 기본 실행 (청크 500자, 오버랩 50자)
python3 ingest_manuals.py

# 청크 크기 조정
python3 ingest_manuals.py --chunk-size 800 --chunk-overlap 100

- 완료되면 data/vector_db/ 폴더가 만들어진다.
- 매뉴얼이 추가되거나 개정되면 다시 실행한다.


[7.8 실습] 매뉴얼 챗봇 대화
------------------------------------------
# 대화형 실행 (여러 질문 연속 가능)
python3 chat_manual.py

# 1회성 질의
python3 chat_manual.py --once "에러코드 E-203 조치 방법은?"

# 검색 청크 수 변경 (기본 3개)
python3 chat_manual.py --k 5

- 종료: exit / quit / 종료 / Ctrl+C
- 답변마다 참고 매뉴얼 파일명과 페이지가 함께 표시된다.


[선택] RAG 검색 정확도 평가
------------------------------------------
# 평가 실행 (첫 실행 시 data/evaluations.json 예시 자동 생성)
python3 evaluate_rag.py

# 청크 수 변경
python3 evaluate_rag.py --k 5

- evaluations.json 에 질문·정답 키워드 쌍을 추가해 평가 셋 확장 가능
- 검색 정확도(관련 페이지를 가져왔는지)와 답변 정확도(제대로 답했는지)를 함께 확인
