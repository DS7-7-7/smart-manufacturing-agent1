사전 준비 (한 번만)
bash
# ollama 서버 + 모델 (로컬로 돌릴 경우)
ollama serve
ollama pull qwen2.5:7b
실행

로컬 ollama (기본)

bash
python main.py

모델 바꾸기

bash
OLLAMA_MODEL=qwen2.5:32b python main.py
OLLAMA_MODEL=qwen2.5:7b python main.py

OpenAI(GPT) 사용

bash
LLM_BACKEND=gpt OPENAI_API_KEY=sk-... python main.py

옵션

bash
python main.py --max-turns 12                 # 협상 턴 상한
python main.py --save-log mylog.json          # 로그 저장 경로
